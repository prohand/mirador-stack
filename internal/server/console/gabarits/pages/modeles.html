Un modèle dit « cette machine est une machine Linux (ou Docker, Proxmox…), donc on y surveille ceci, avec ces alertes et ces seuils ». Attribuez-le à une machine (sur sa page) ou à un groupe (ici) : toutes les machines du groupe le reçoivent. Les modèles se cumulent ; un seuil se règle pour le groupe ici, et pour une machine sur sa page. Quand un modèle a une règle équivalente à une règle importée, celle-ci se tait pour les machines qui portent le modèle.
