Modèles de surveillance

{{template "onglets-machines" "modeles"}}

Un modèle dit « cette machine est une machine Linux (ou Docker, Proxmox…), donc on y surveille ceci, avec ces alertes et ces seuils ». Cocher ici les modèles de chaque groupe (toutes ses machines les reçoivent), ou sur la page d'une machine. Quand un modèle a une règle équivalente à une règle importée, celle-ci se tait pour les machines qui portent le modèle.
