Installer Olvid

{{template "onglets-reglages" (onglet $ "olvid")}}

Le bot Olvid tourne dans son propre conteneur (le daemon officiel). mirador ne pilote jamais Docker (ce serait lui donner les droits root sur le serveur) : vous lancez le conteneur, l'assistant fait le reste.

{{if .D.Actif}}

Olvid est déjà activé. Refaire l'assistant crée une nouvelle clé client (l'identité du bot est reprise si elle porte le même nom).

{{end}}

1. Lancer le daemon Olvid

Sur le serveur, dans le dossier du docker-compose.yml de mirador, en root :

grep -q OLVID_ADMIN_CLIENT_KEY_CLI .env 2>/dev/null || echo "OLVID_ADMIN_CLIENT_KEY_CLI=$(openssl rand -hex 32)" >> .env
chmod 600 .env
docker compose --profile olvid up -d
grep OLVID_ADMIN_CLIENT_KEY_CLI .env

La dernière ligne affiche la clé admin du daemon, à coller à l'étape 2. Un daemon déjà installé ailleurs convient aussi : donner son adresse et sa clé admin.

2. Connecter mirador au daemon

{{template "csrf" .CSRF}}
La clé admin sert une seule fois : créer l'identité du bot et une clé client pour mirador. Elle n'est ni gardée ni journalisée ; seule la clé client est enregistrée (chiffrée). {{template "code2fa"}}

3. Ensuite

La page Olvid s'ouvre : inviter le bot depuis votre téléphone (QR code), échanger les codes à 4 chiffres, puis choisir la discussion qui reçoit les alertes. Enfin, dans Notifications, choisir Olvid comme canal principal ou de secours.

{{end}}
