Mises à jour des agents

MachinesMises à jour des agentsConfiguration des agents

Seuls les agents installés avec --auto-update se mettent à jour. Chaque version est signée par la CI de GitHub à chaque tag (ou à la main avec mirador-release) ; le serveur vérifie la signature et ne signe jamais. Déploiement conseillé : assigner d'abord la version à une machine test (page de la machine), attendre son battement, puis l'assigner à toutes.

Clé publique affichée par mirador-release cle sur ton poste (la clé privée n'en sort jamais). Le script d'installation la récupère ici et l'écrit sur la machine dans un fichier root (/etc/mirador-agent/cles-publiques.txt) que l'agent ne peut pas modifier. La changer ici ne touche pas les machines déjà installées : pour elles, relancer le script avec --cle-publique. Deux clés au plus (l'actuelle et la suivante, pour changer de clé).
