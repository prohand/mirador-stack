Équipement sans agent

Pour un appareil qui n'accepte pas l'agent. Deux cas : il envoie lui-même ses métriques au format InfluxDB v2 (OPNsense avec le plugin Telegraf : un token est créé, affiché une seule fois), ou il est relevé par un collecteur du LAN (Synology, UniFi, imprimante… : choisir le collecteur, pas de token). La machine est créée et approuvée tout de suite.
