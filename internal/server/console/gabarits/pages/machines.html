Ajouter une machine

{{if not .D.Ingestion}}

Adresse d'ingestion pas encore renseignée : la renseigner dans Réglages › Interface.

{{end}} {{$srv := "https://ADRESSE-INGESTION"}}{{if .D.Ingestion}}{{$srv = .D.Ingestion}}{{end}}{{$j := "JETON"}}{{if .D.Jeton}}{{$j = .D.Jeton}}{{end}}

1. Choisir le nom (facultatif : sinon le nom d'hôte de la machine), le site, le type et le groupe, puis créer un jeton (ci-dessous). 2. Sur la machine, en root, coller :

curl -fsSL {{$srv}}/api/agent/v1/install -o mirador-agent-install.sh
 MIRADOR_JETON={{$j}} bash mirador-agent-install.sh --serveur {{$srv}}{{if .D.OptionEnvoi}} {{.D.OptionEnvoi}}{{end}}

Adresse utilisée : celle d'ingestion (vhost des agents, Réglages › Interface), pas celle de cette interface. Le script télécharge ensuite le binaire de l'agent (amd64 ou arm64, détecté) avec le jeton et vérifie son empreinte. Le jeton ne sert qu'une fois et expire ; passé par la variable MIRADOR_JETON, il n'apparaît pas dans la liste des processus, et l'espace en début de ligne le garde hors de l'historique bash. La machine doit être autorisée dans le vhost d'ingestion (nginx). Sans curl : wget -O mirador-agent-install.sh …. Hors ligne : --binaire FICHIER. Métriques et logs se changent ensuite par machine, groupe ou pour toutes : Configuration des agents (« Métriques de la machine », « Logs du journal », « Logs Docker »).

3. La machine apparaît ici « en attente » : l'approuver.
